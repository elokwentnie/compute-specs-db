Import from CSV

Import CPUs from a CSV file. You can either upload a file or import from the repository CSV.

Bulk imports only change the live database. They are not written to the CSVs on GitHub, so they are lost on the next restart. To change data permanently, use the Browse, Create and Edit tabs.

Option 1: Import from Repository CSV

Imports from cpu_spec_validated.csv bundled with the deployed app.

Option 2: Import GPUs from Repository CSV

Imports from gpu_spec_validated.csv in the repository.

Option 3: Upload CPU CSV File

Upload a CSV file to import. Comma- or semicolon-delimited, with the same columns as cpu_spec_validated.csv.
