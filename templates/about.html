Compute Specs DB is a free, open catalog of server hardware specifications. It currently lists {{ cpu_count }} server-class processors across {{ cpu_families }} product families and {{ codenames }} generations, and {{ gpu_count }} datacenter GPUs and accelerators. Every model has its own page, and the whole dataset can be searched, compared and downloaded.

Where the data comes from

Specifications are collected from manufacturers' official product pages and datasheets, such as Intel's product specifications (ARK), AMD's processor and accelerator pages, NVIDIA's datasheets and Ampere's Altra specifications. Processor generation codenames, which manufacturers don't always list, were confirmed by hand with TechPowerUp's CPU database. Where sources disagree, the manufacturer's own documentation takes precedence.

How validation works

Each entry carries a status. Validated means the values have been checked by hand against official manufacturer sources. Unverified means the entry was added but has not been checked yet, so treat it with care. {{ validated }} of {{ cpu_count + gpu_count }} entries are currently validated.

Some values are simplifications: turbo frequency is the highest single-core boost, TDP is the default rating even when a processor can be configured higher or lower, and maximum memory is the largest amount one processor supports.

Corrections and new models

Every spec page has a Report an error form; no account is needed. Missing models can be suggested on the suggestion page. Reports and suggestions are reviewed by hand before anything changes, and every change to the data is recorded in the public GitHub repository, so the full history of each entry is visible.

Using the data

The data is free to use under the MIT licence. You can download all CPUs as CSV or all GPUs as CSV, or query the JSON API. If you use it in an article, paper or tool, please link to the relevant spec page or to this site.

Independence

Compute Specs DB is an independent open-source project. It is not affiliated with or endorsed by Intel, AMD, NVIDIA or any other manufacturer, and product names are trademarks of their owners.

Frequently asked questions

Is Compute Specs DB free?

Yes. The website, the API and the downloads are free, and the data is MIT-licensed.

Can I use the data in my own project or product?

Yes, including commercially, under the terms of the MIT licence. A link back is appreciated.

What does "unverified" mean?

The entry has not yet been checked against official manufacturer sources. It may still be correct, but double-check important values before relying on them.

Why is a processor or GPU missing?

The catalog focuses on server and datacenter hardware and grows over time. Suggest a missing model and it will be reviewed.

Does the site include prices or benchmarks?

No. It lists manufacturer specifications only. Prices change too quickly to track reliably, and benchmark results depend heavily on the workload and configuration.
